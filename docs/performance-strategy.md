# Performance Strategy

- Server components are used by default.
- Client components are limited to navigation, hotspots and the contact form.
- The supplied city image is local and rendered with Next Image.
- Below-fold images should be lazy by default through Next Image.
- No Wix scripts are migrated.
- No analytics scripts are installed.
- No 3D framework is installed before a real model exists.
- Reduced motion disables the moving partner strip.
- Future WebM/mobile imagery should be separate from desktop assets.

## Before Launch

- Optimise large PNG assets to WebP/AVIF.
- Add real responsive images for product and project pages.
- Run Lighthouse on representative routes.
- Check cumulative layout shift on image-heavy sections.
